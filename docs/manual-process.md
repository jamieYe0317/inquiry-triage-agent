# Before and after: the steps to sort one inquiry

This page counts steps. It does not estimate time. A timed trial is still open (see `PLAN.md`, section 9).

## By hand (10 steps)

A person at the fictional company does these steps for each website inquiry:

1. Open the web-form inbox and read the message.
2. Decide what kind of request it is: machine trouble, quality complaint, partner request, or other.
3. Decide if the sender is a private customer or a business.
4. Find the model and serial number in the text, or note that they are missing.
5. Decide if anyone is at risk (smoke, fuel leak, injury).
6. Find the right manual, guide, or policy, and the right section in it.
7. Write a short summary for the team.
8. Pick the team and the priority.
9. Forward the message and the summary.
10. Write a first reply to the sender.

## With the agent (3 steps)

The agent does steps 2 to 9 and drafts step 10. The person does these steps:

1. Read the case card.
2. Check the type, the team, and the draft. Fix them if they are wrong.
3. Edit and send the holding reply, then work the case.

## What the count does not show

- A step count is not a time measurement. Some steps by hand take seconds, and some take minutes.
- Step 2 with the agent is real work. The person must still catch the agent's mistakes. The eval reports how often the agent is wrong.
